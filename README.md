
# Job Portal Application

A web-based Job Portal built using Django REST Framework that allows users to view and manage job postings. The backend provides secure REST APIs with authentication and PostgreSQL database support, while the frontend is styled using Tailwind CSS.



## Tech Stack

**Backend**

* Django
* Django REST Framework
* PostgreSQL
* REST API
* Basic Authentication / JWT

**Frontend**

* HTML
* Tailwind CSS
* JavaScript
